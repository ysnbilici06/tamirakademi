# Tamir Akademisi

Telefon ve tablet tamirini sıfırdan öğreten, marka bağımsız ve ücretsiz bir kurs uygulaması.

- Sunucu gerekmez: HTML, CSS ve JavaScript ile yazıldı; ilerleme tarayıcıda saklanır.
- Telefona kurulabilir (PWA) ve internet olmadan da çalışır.
- Açık ve koyu tema.

Denemek için `index.html` dosyasını açman yeterli. Telefona kurmak için yayınlanan adresi aç ve "Ana ekrana ekle"yi seç.

> Eğitim amaçlıdır. Cihazını açmak garantiyi bozabilir; tüm işlemler senin sorumluluğundadır.
